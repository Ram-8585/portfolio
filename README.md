# Portfolio Website

My personal portfolio — a responsive single-page site built with vanilla
**HTML, CSS and JavaScript** (no frameworks), deployed on GitHub Pages.

🔗 **Live demo:** https://ram-8585.github.io/portfolio/

## Sections

- **Hero** — name, tagline and call-to-action buttons
- **About** — background, education and certifications
- **Skills** — HTML, CSS, JavaScript, React (learning), Java, Git & GitHub
- **Projects** — portfolio site plus placeholders for upcoming JS and React apps
- **Contact** — email, GitHub and LinkedIn links

## Run locally

Just open `index.html` in a browser — no build step, no dependencies.

```bash
# or serve it locally with Python:
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy (GitHub Pages)

1. Push this folder to a GitHub repo named `portfolio`
2. Repo **Settings → Pages** → deploy from the `main` branch
3. Your site goes live at `https://<username>.github.io/portfolio/`

## Contact details

The site's email and LinkedIn links are filled in with the owner's real details.
